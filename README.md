# Demand Forecasting API

A small portfolio demo: a **FastAPI** service that serves a
scikit-learn `GradientBoostingRegressor` trained to forecast product demand.

> **This is a portfolio project built with fully synthetic data.**
> The training set is generated by `scripts/train_model.py` and only stands in
> for what real product-demand data would look like. No employer or proprietary
> code is involved.

## How it works

1. `scripts/train_model.py` generates 5,000 synthetic rows
   (`price`, `day_of_week`, `month`, `promotion`, `stock_on_hand` → `demand`)
   and trains a `GradientBoostingRegressor`, saving it to `model.joblib`.
2. `app/` exposes the trained model over HTTP.

## Quick start

```bash
pip install -r requirements.txt

# 1. Train and save the model
python scripts/train_model.py
# -> Test MAE: 10.46 units

# 2. Run the API
uvicorn app.main:app --reload

# 3. Run the tests
pytest tests/ -v
```

Or with Docker:

```bash
docker build -t demand-api .
docker run -p 8000:8000 demand-api
```

## Endpoints

| Method | Path          | Description                          |
|--------|---------------|--------------------------------------|
| GET    | `/health`     | Liveness check                       |
| GET    | `/model-info` | Model metadata (version, features)   |
| POST   | `/predict`    | Demand forecast for one product row  |

## Examples

```bash
curl http://localhost:8000/health
# {"status":"ok"}

curl http://localhost:8000/model-info
# {"version":"1.0.0","artifact_path":"model.joblib",
#  "model_type":"GradientBoostingRegressor",
#  "features":["price","day_of_week","month","promotion","stock_on_hand"],
#  "trained_on":"synthetic product-demand data (see scripts/train_model.py)"}

curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"price": 25.0, "day_of_week": 5, "month": 12, "promotion": true, "stock_on_hand": 200}'
# {"predicted_demand":173.82,"model_version":"1.0.0"}
```

A request with an out-of-range `day_of_week` returns `422 Unprocessable Entity`
with a Pydantic validation error.
